# Industrial Monitoring Database
## 📌 Project Overview
This project simulates an industrial equipment monitoring system using relational database concepts.
The database stores:
- Machines
- Sensors
- Sensor readings
- Maintenance records
## 🏭 Industrial Context
The system models industrial equipment used in manufacturing environments for monitoring machine performance and sensor data.
## 🛠 Technologies Used
- PostgreSQL
- SQL
- Relational Database Design
## 🎯 Skills Demonstrated
- Table creation
- Primary and Foreign Keys
- SQL Relationships
- JOINS
- Querying industrial monitoring data
